❓ Cooper Control Panel — Help

This panel controls Cooper, the One Comcentre AgiBot X2 Ultra ambassador robot. All buttons talk directly to Cooper over the network.

Server status bar (top of the screen)

Shows whether Cooper's web server is up and running at the address chosen in Settings. Green = online and ready; red = the panel cannot reach Cooper — controls are disabled until the connection comes back. If it stays red, check that Cooper is powered on, on the network, and that the right setup is selected in ⚙ Settings.

⚙ Settings — Connection

  • Where is Cooper being used? — one selection covers the three setups: Show suite (this page hosted on the optimus PC; Cooper at its fixed suite address), Cooper's built-in webserver (page served by Cooper itself; address is automatic), and Outside event (portable setup — type Cooper's address on the event network).
  • IP address / port — Cooper's network address. Locked for the first two setups because the address is known; editable for events. The value you type at an event is remembered separately, so returning to the show suite never loses it.
  • Panel PIN — required for every control action (listening, dance, show, shortlist changes). Enter it once per device; it is remembered. Without the PIN the panel can only view status.
  • Connect — saves the settings and tests the connection. Normally not needed: the panel connects by itself when opened.

Listening

The switch turns Cooper's microphones on or off. Off (muted) means Cooper ignores surrounding conversation and will not answer the audience. During a show the script controls the microphone itself: muted at the start, and it stays muted afterwards unless "listen again after show" is ticked.

Actions

One-tap gestures Cooper performs immediately: 🤝 Shake hand, 🫶 Heart sign (both hands), 👋 Right-hand goodbye, and 😘 Blow kiss. They move the robot only — no speech, and the microphone is not affected. The buttons are disabled while a full show is running so gestures cannot interrupt the performance.

Performance

  • Dance list — the songs available for the show (filtered by the shortlist, if one is set). ↻ reloads the list from Cooper.
  • ▶ Run full show — the complete sequence: wave + welcome, introduction, dance, bow, clap, thank-you + heart, goodbye + blow kiss, goodbye wave. Buttons lock while a show is running.
  • Play dance only — just the selected dance, nothing else. Does not touch the microphone.
  • listen again after show — tick to have Cooper resume listening when the show ends.

Personalize messages

  • Tenant company / guest name — write {name} anywhere in a message and Cooper speaks this name there. Blank = "everyone".
  • Welcome (morning / afternoon) — two versions of the welcome; Cooper picks by its own clock at show time (morning before 12:00). Fill only one to use it all day.
  • Introduction — spoken after the welcome, before the dance. Note: the "2 meters distance" safety line lives here.
  • Goodbye — spoken near the end, with the blow kiss.
  • Every field is spoken exactly as written; blank fields fall back to the built-in lines. Reset to default messages restores all.

Dance song shortlist (in ⚙ Settings)

Tick the songs that should appear in the main dance list; untick to hide. Nothing ticked = every song is shown. The shortlist is stored on Cooper, so all devices share the same list (changing it needs the PIN). When the AgiBot LinkCraft cloud pushes new songs, a "✨ new dance songs" banner appears — press Review, tick the ones you want, then Mark NEW as seen to clear the alert everywhere.

Performance diagnostics (in ⚙ Settings)

For checking how fast Cooper responds. When on, each button press logs the time split into network (Wi-Fi), server (processing on Cooper), and robot (Cooper's controller accepting the command), with a flow diagram and a live show timeline (launch → first speech → dance → goodbye → complete, measured from your click). Green is fast, amber is slow, red needs attention. Leave off for daily use.

If something is not working

  • Red server bar — Cooper off, wrong setup selected, or network issue. Check ⚙ Settings first.
  • "PIN required" / "invalid PIN" — enter the correct PIN in ⚙ Settings.
  • Dance list empty — press ↻; if still empty, Cooper's dance services may still be starting up.
  • Robot reacts slowly — turn on Performance diagnostics and see which part (network / server / robot) is taking the time.
